## auRAM — Landing Page Cinematográfica

Landing page premium inspirada na estética BlackGold para a marca **auRAM**.

### Stack

- **Next.js** (App Router)
- **React**
- **TailwindCSS**
- **Framer Motion**
- **Three.js (opcional)** — ainda não utilizado no layout, mas incluído em dependências para futura cena 3D de RAM.

### Rodando o projeto

```bash
npm install
npm run dev
```

Depois abra `http://localhost:3000` no navegador.

### Conceitos de design

- Fundo preto profundo `#0B0B0B`
- Acessos em ouro `#D4AF37`
- Texto branco suave `#F5F5F5`
- Glow radial sutil em ouro
- Seções 100vh com **scroll snap** vertical suave
- Tipografia grande, minimalista e cinematográfica
- Animações elegantes com **Framer Motion**
